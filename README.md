# amstutzcreative.co

Static one-page site for Amstutz Creative. No build step — `index.html`
plus `assets/`. Deployed to GitHub Pages from `main`.

- `index.html` — the whole site
- `assets/img/` — 71 WebP frames (g## above the fold, w## in the lower gallery)
- `assets/logo/` — client marks

Images are exported from the source library at display resolution.
Everything below the fold is `loading="lazy"`.
